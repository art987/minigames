我建议把这个网站定位为：一个通过每日短篇朗读，逐步建立英语口语表达能力的学习平台。

核心不是让用户学习大量单词和语法，而是让用户通过每天一篇文章，逐渐形成英语思维，积累生活表达，最终能够自然地用英语交流。

我认为整个课程体系应该遵循四个原则：

1. 短小有成就感：每天 1 篇，初期约 30～60 秒，中后期也尽量控制在 2～3 分钟。
2. 循序渐进：从简单句子到复合表达，从描述事物到表达观点。
3. 生活全覆盖：围绕真实生活场景，而不是围绕语法知识点编排。
4. 重复但不枯燥：重要表达在不同文章、不同情境中反复出现，让用户真正掌握，而不是读过就忘。

# 三、每篇文章的标准规范

建议所有文章使用统一的内容结构，方便网站自动化生成和管理。

# My Daily Life

我的日常生活 · 预计朗读 40 秒

英文原文

I usually get up at seven in the morning. I wash my face and brush my teeth. Then I have breakfast. I like eggs and bread. After breakfast, I start my day. I try to stay positive and enjoy every moment.

中文翻译

我通常早上七点起床。我洗脸、刷牙，然后吃早餐。我喜欢鸡蛋和面包。早餐后，我开始新的一天。我努力保持积极的心态，享受每一刻。

今日重点表达

| 表达             | 中文   |
| -------------- | ---- |
| get up         | 起床   |
| wash my face   | 洗脸   |
| brush my teeth | 刷牙   |
| have breakfast | 吃早餐  |
| stay positive  | 保持积极 |

开口练习

1. What time do you get up?
2. What do you usually eat for breakfast?
3. What do you do after breakfast?

练习目标：将文章中的表达替换成自己的真实生活。

每篇文章建议固定包含：

1. 英文标题。
2. 中文标题。
3. 英文朗读正文。
4. 中文翻译。
5. 5～8 个核心表达。
6. 2～3 个口语问答练习。
7. 美式英语发音音频。

其中，正文是核心，其他内容都是辅助。不要让辅助内容比正文还复杂。

# 五、文章编排必须遵循的原则

我建议建立以下 5 条内容生产规则：

- 场景连续性：相邻文章可以形成生活上的联系，但不能每天都写同一种事情。
- 表达复现：以前学过的核心词汇和句型，在后续文章中自然出现。
- 内容多样性：不要连续多天都用第一人称描述日常作息。
- 难度递增：每 7 天设置一次轻量复习，复用旧表达并加入少量新内容。
- 真实自然：文章要像美国人日常真正会说的话，而不是中文思维逐字翻译出来的英语。

# 八、我认为还应该增加一个重要设计：真正的口语成长

网站不能只是一个英语文章阅读器。

建议围绕一篇文章设计四个学习动作：

第一步：阅读理解

理解文章内容，知道每句话是什么意思。

第二步：听力跟读

听美式发音，逐句跟读，模仿语音、语调和节奏。

第三步：开口表达

不看原文朗读，再回答文章后面的口语问题。

第四步：表达迁移

将文章中的句型替换成自己的生活内容，真正学会运用。

我的最终建议：

先不要急着生成 365 篇文章。应该先把六阶段的难度标准、12 个生活主题、365 天的文章目录全部确定，再按照目录批量创作。

# 十、我建议再确定三个内容标准

这三个标准会直接决定最终文章的质量。

1\. 英语必须以美式日常口语为基础

避免教科书式表达，优先使用美国人日常真正使用的词汇、短语和句型。

2\. 文章必须有内容，而不只是练习句子

比如你截图中的：

If you spend 5 minutes scrolling through social media, you might think that good love is all about grand romantic gestures...

这种文章有观点、有情境、有表达价值。即使短，也能让人读完有所收获。

3\. 每个阶段都应该有不同的内容气质

- 初级：轻松、简单、亲切。
- 中级：真实、有趣、实用。
- 中高级：有故事、有情绪、有观点。
- 高级：有思想、有深度、有交流价值。

# 英语朗读课程 AI 内容生成规范 V1.0

## 一、项目定位

**课程名称：每日英语口语朗读课程**

核心目标：通过循序渐进的短篇英语文章，帮助学习者逐渐掌握自然、美式、实用的日常英语表达。

### 核心教学原则

1. 以生活场景为中心，而不是以语法知识点为中心。
2. 以自然口语为基础，而不是机械地翻译中文。
3. 以意群为阅读单位，而不是简单地逐词切割。
4. 以理解和运用为目的，而不是单纯背诵。
5. 以循序渐进为原则，控制词汇、句式和表达难度。
6. 以短篇阅读为载体，让学习者每天都能获得完成感。

### 目标用户

- 希望提高英语听力和口语能力的普通成年人。
- 能够认识一些英语单词，但不擅长连贯表达的人。
- 希望通过每天少量练习积累生活英语的人。
- 希望逐渐建立英语表达习惯的人。

不以专业英语、学术英语、商务英语为主。

## 二、六阶段难度控制标准

所有文章必须严格遵守以下阶段规范。

| 阶段   | 天数      | CEFR参考  | 单词数量    | 预计朗读时间  |
| ---- | ------- | ------- | ------- | ------- |
| 第一阶段 | 001–045 | A1      | 30–50   | 20–40秒  |
| 第二阶段 | 046–105 | A1–A2   | 50–75   | 30–50秒  |
| 第三阶段 | 106–180 | A2      | 70–100  | 40–70秒  |
| 第四阶段 | 181–255 | A2–B1   | 90–120  | 50–85秒  |
| 第五阶段 | 256–315 | B1      | 110–140 | 60–100秒 |
| 第六阶段 | 316–365 | B1–B2过渡 | 130–160 | 70–115秒 |

注：朗读时间为参考值，实际取决于语速。CEFR等级是内容难度参考，不代表完成文章就获得相应语言等级。

### 1. 第一阶段：基础启蒙

- 以一般现在时为主。
- 使用最常见的生活词汇。
- 以简单陈述句为主。
- 每句话尽量只表达一个主要信息。
- 可以使用简单疑问句。
- 少量使用 and、but。
- 避免复杂从句、抽象概念和生僻词。

目标：能够介绍自己、描述身边事物、表达简单需求。

### 2. 第二阶段：日常交流

- 开始出现一般过去时、一般将来时。
- 引入常见生活动词短语。
- 使用 because、when、so 等连接词。
- 开始出现简单对话。
- 可以描述生活中的具体过程。
- 逐渐学会询问、请求、感谢和拒绝。

目标：能够处理常见生活场景。

### 3. 第三阶段：情境表达

- 灵活使用过去、现在和将来时态。
- 开始使用宾语从句、时间状语从句等常见结构。
- 能够描述问题、经历和解决过程。
- 增加情境对话和连续叙述。
- 学习表达原因、结果、条件和计划。

目标：能够围绕一个具体场景连续表达。

### 4. 第四阶段：自然交流

- 增加复合句和多种表达方式。
- 学会描述情绪、经历和人际关系。
- 引入自然的口语连接表达。
- 能够表达同意、反对、建议和个人感受。
- 开始出现一定的观点交流。

目标：能够自然地与他人交流生活话题。

### 5. 第五阶段：深入表达

- 能够使用复杂一些的句式。
- 能够解释原因、比较观点。
- 学会表达抽象一些的概念。
- 使用 although、however、instead、unless 等表达。
- 能够讲述具有逻辑性的个人经历。
- 增加观点、判断和价值思考。

目标：能够清楚表达自己的想法。

### 6. 第六阶段：综合运用

- 灵活切换不同的时态。
- 使用多层次句子结构。
- 能够展开完整的观点论述。
- 能够进行假设、比较和推理。
- 能够自然地描述复杂生活经历。
- 允许使用更丰富的地道口语表达。

目标：能够围绕熟悉的话题进行较完整、自然的英语交流。

## 三、文章内容生成标准

### 1. 内容真实性

每篇文章必须围绕真实生活中可能出现的情境。

优先选择：

- 真实的生活经历。
- 常见的人际交流。
- 普通人的日常需求。
- 真实的情绪体验。
- 有意义的生活观察。
- 普通人能够理解和参与的话题。

禁止：

- 为了练习语法而编造不自然的句子。
- 为了凑字数反复表达同一个意思。
- 使用明显不符合美国日常交流习惯的表达。
- 使用大量生僻词制造难度。
- 将中文表达机械翻译成英文。

### 2. 内容价值

每篇文章至少具备以下一种价值：

- 实用价值：学会一种生活表达。
- 知识价值：了解一种生活常识。
- 情感价值：引发情绪共鸣。
- 思考价值：产生新的认识。
- 故事价值：了解一段真实感较强的生活经历。

不要让所有文章都变成简单的生活流水账。

### 3. 内容多样性

文章形式应当交替出现：

- 第一人称生活描述。
- 第二人称建议与引导。
- 第三人称人物故事。
- 两人之间的日常对话。
- 生活事件叙述。
- 观点分享。
- 情境问题解决。

避免连续多篇都采用相同的开头、相同的叙述方式和相同的结尾。

## 四、英文语言质量规范

### 1. 美式英语优先

所有正文以自然的美式英语为基础。

例如：

优先使用：

- apartment
- elevator
- vacation
- sneakers
- gas station

避免在普通美式语境中无必要地混用英式表达。

### 2. 口语自然度

优先使用美国人日常交流中常见的表达。

例如：

自然：

- I'm running a little late.
- That sounds like a good idea.
- I didn't see that coming.
- Let me think about it.

避免：

- I am currently in a state of being delayed.
- This proposal sounds agreeable to me.

### 3. 句子长度

根据阶段逐步提高句子复杂度。

初级：尽量使用短句。

中级：可以使用适度的复合句。

高级：可以使用较长的复合结构，但必须保证朗读自然。

不要单纯通过拉长句子增加难度。

### 4. 词汇重复机制

建议采用以下内容比例：

- 约70%：已经接触过的基础词汇、常用短语和句型。
- 约30%：新的词汇、短语和表达方式。

这是整体编排的参考比例，不要求每篇严格计算。

核心目标是让学习者在不同生活场景中反复遇到熟悉表达，同时持续获得新的语言输入。

## 五、文章意群划分规范

这是本网站最重要的技术规范之一。

### 1. 基本原则

必须按照英语自然表达习惯进行意群划分。

一个意群应当是一个具有相对完整语义、能够自然朗读的语言单位。

例如：

原句：

If you spend 5 minutes scrolling through social media, you might think that good love is all about grand romantic gestures.

推荐划分：

If you / spend 5 minutes / scrolling through / social media, / you might think / that good love / is all about / grand romantic gestures.

禁止：

- 按照固定单词数量机械切割。
- 将紧密相关的词汇拆开。
- 将介词与其宾语随意拆开。
- 将冠词与名词拆开。
- 将助动词与其动词随意拆开。
- 将固定短语拆得无法理解。

### 2. 意群长度

| 阶段   | 建议每个意群 |
| ---- | ------ |
| 第一阶段 | 1–4个单词 |
| 第二阶段 | 2–5个单词 |
| 第三阶段 | 2–6个单词 |
| 第四阶段 | 2–7个单词 |
| 第五阶段 | 3–8个单词 |
| 第六阶段 | 3–9个单词 |

以上是建议范围，不是强制限制。

如果一个固定表达本身较长，应当保持完整，不要为了控制长度而错误切分。

### 3. 意群划分示例

原句：

I usually take a short walk after dinner because it helps me relax.

建议划分：

I usually / take a short walk / after dinner / because / it helps me relax.

每个意群必须能够独立提供合理的阅读理解。

### 4. 标点处理

- 逗号、句号、问号等必须保留。
- 句末标点归属于对应意群。
- 不允许改变原文标点和语义。
- 不允许为了划分意群而修改原句。

## 六、每篇文章的完整数据结构

每篇文章必须生成以下内容：

### A. 基础信息

- article_id：文章唯一编号。
- day：课程天数。
- stage：所属阶段。
- category：生活主题。
- scene：具体场景。
- title_en：英文标题。
- title_cn：中文标题。
- difficulty：难度等级。
- word_count：正文单词数量。
- estimated_reading_time：预计朗读时间。

### B. 英文正文

- content_en：完整英文正文。
- content_cn：完整中文翻译。

英文正文必须是自然、连贯、完整的文章。

### C. 意群数据

每个句子必须拆分成若干意群。

每个意群必须包含：

- chunk_en：英文意群。
- chunk_cn：该意群在当前语境中的中文解释。
- words：组成该意群的单词列表。
- pronunciation：意群朗读所需的发音信息。

注意：意群中文解释应优先体现实际语境，不必机械逐字翻译。

### D. 单词数据

每个值得学习的单词包含：

- word：单词。
- phonetic：美式音标。
- meaning：当前语境中的中文含义。
- pronunciation：单词发音音频标识。
- part_of_speech：词性。

对于同一个单词存在多种含义的情况，必须根据上下文确定当前含义。

### E. 核心表达

每篇建议选取5～8个重点表达。

每个表达包含：

- expression：英文表达。
- meaning：中文含义。
- example：原文中的使用示例。

优先选择真正值得学习的固定搭配、短语动词和日常口语表达。

### F. 整句理解

每个完整句子包含：

- sentence_en：英文原句。
- sentence_cn：自然中文翻译。
- sentence_explanation：必要的语义、语法或表达习惯说明。

解释应该简洁，不需要把每句话都写成语法课。

### G. 口语练习

每篇设置2～3道问题。

要求：

- 与文章主题相关。
- 鼓励学习者联系自己的生活。
- 不要求机械复述原文。
- 难度符合当前阶段。

## 七、中文翻译规范

中文翻译不是逐字对应，而是忠实传达英文的真实意思。

要求：

1. 语义准确。
2. 中文自然通顺。
3. 不遗漏原文信息。
4. 不擅自添加原文没有的内容。

推荐：

你的网页已经有单词点击朗读、意群注解和整句理解，所以我建议数据库不要只存储整篇文章，再让前端临时切割。

```
  "sentence_cn": "晚饭后我通常会散一会儿步。",
  "chunks": [
    {
      "text": "I usually",
      "meaning": "我通常",
      "words": ["I", "usually"]
    },
    {
      "text": "take a short walk",
      "meaning": "散一会儿步",
      "words": ["take", "a", "short", "walk"]
    },
    {
      "text": "after dinner.",
      "meaning": "晚饭后",
      "words": ["after", "dinner"]
    }
  ]
}
```
