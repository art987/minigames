# TickLife · 嘀嗒人生

> 记录一切，包括空白。——像秒表一样，以最少动作连续记录每天在做的事，事后回溯"时间都花在哪"。

## 关于 TickLife

- **Tick**：秒针走动的声音，对应 APP 里机械秒表的视觉与听觉反馈。
- **Life**：把微观的"秒"连接到宏观的"人生"——时间在一分一秒减少，只记录、不评判。
- 核心理念：**不评判，只呈现**。发呆、刷手机、走神……无意义的时间被如实留下痕迹，复盘时才真正看见"时间黑洞"。

## 功能亮点

- ⏱️ 秒表风格深色 UI（圆形刻度盘 + 红绿指针 + 毫秒走时）
- 🔁 事件**倒序**排列（最新置顶）
- 🔴 主按钮：**蓝色「开始」↔ 红色「新记录」**，点即开始新段并弹窗
- ↔️ 图标**单行横向滑动** + **点选即关闭弹窗**
- ❔ 「跳过（未知）」灰色图标 —— **记录无意义**核心特色
- ✎ 编辑弹窗：补/改图标、文字、预估用时
- ⏳ 预估用时刻选：5/10/20/30/40 分，1/1.5/2/2.5/3 小时 + **自定义时间滑轮**（时 0–12、分 0/5/…/55 双列滑动）
- 📅 按天聚合、跨天继续计时、当天顶部毫秒计时器
- 💾 LocalStorage 持久化 + JSON 一键导出（`ticklife-YYYY-MM-DD.json`）
- 🕳️ **「时间黑洞」复盘页**：顶栏点 🕳️复盘 进入，支持**本周/本月**切换，含：
  - **无意义占比圆环**：未知/未命名事件占已记录时间的比例（橙色 = 黑洞，绿色 = 有意义）。
  - **时间黑洞 · 最长事件 TOP5**：按耗时排序的横向条形榜，直观暴露"时间都黑洞去哪了"。
  - **预估 vs 实际对比**：为有预估用时的事件并列显示预估（浅绿底）与实际（亮绿），标注"超/省"多少分钟。

## 手机实时预览

### 方式 A：手机浏览器直开（最简单）
1. 将 `time-tracker-prototype.html` 传到手机（微信文件助手 / AirDrop / 数据线）。
2. 手机浏览器（Safari / Chrome）打开该文件即可全屏体验。

### 方式 B：电脑起本地服务 + 同 Wi-Fi 访问（可热更新）
```bash
# 在该文件所在目录执行（Python 3）
python3 -m http.server 8080
# 或 Node 方式
npx serve -p 8080
```
手机浏览器访问 `http://<电脑局域网IP>:8080/time-tracker-prototype.html`
（Mac 查 IP：`ifconfig | grep inet`；Windows：`ipconfig`）

## 操作节奏

1. 点 **开始** → 弹窗左右滑图标行点一个（或点「跳过（未知）」）→ 记录开始。
2. 想换段 → 点红色 **新记录** → 上一段结束、新段立即开始 → 再滑选图标。
3. 事后补完善 → 点事件右侧 **✎** → 补图标 / 文字 / 预估用时。
4. 满屏灰色「❔未知」即"无意义时间"的可视化——产品灵魂所在。
5. 点顶栏 **🕳️复盘** 进入时间黑洞页 → 切「本周/本月」查看圆环占比、最长事件榜、预估 vs 实际。点顶栏 **TickLife** 字样返回主界面。

## 技术说明

- 单文件 H5（`.html`），**零外部依赖**，可直接在浏览器运行。
- 数据保存在浏览器 LocalStorage（键：`ticklife:v1`），清缓存会丢失，建议定期「导出 JSON」备份。
