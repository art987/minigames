# ARTKNIT STUDIO 技术架构调整通知

项目正式确定为纯前端 Web 应用，不再开发 Tauri 桌面程序。

## 一、技术要求

采用：

- React
- TypeScript
- Vite
- Tailwind CSS
- Zustand
- HTML Canvas 2D
- IndexedDB
- JavaScript 图像处理算法

所有核心功能在浏览器本地运行。

禁止引入：

- C++
- Python
- Tauri
- Electron
- SQLite
- 必须依赖服务器的业务逻辑
- 远程 AI API

## 二、核心运行原则

1. 用户打开网页即可使用。
2. 图片在浏览器本地处理。
3. 色卡和图案保存到 IndexedDB。
4. 关闭浏览器后，作品仍然存在。
5. 不上传用户图片到服务器。
6. 核心功能支持离线运行。
7. 使用 Web Worker 处理较复杂的图像算法，避免阻塞界面。
8. 采用 Canvas 2D 实现高性能针织像素网格预览与编辑。

## 三、实时预览

用户修改针数、行数、色卡、颜色数量或算法参数时，应自动更新预览。

采用快速预览和完整转换两种处理策略：

- 快速预览用于交互过程。
- 完整转换用于最终生成高质量矩阵。
- 对频繁变化的参数进行防抖处理。
- 旧任务应能取消或忽略，避免结果覆盖最新操作。

## 四、数据结构

继续使用 ARTKNIT STUDIO 自定义 AKN 数据标准。

针织矩阵、色卡、转换参数、原始图片等数据均保存在本地。

## 五、开发要求

请先检查当前项目。

如果第一阶段已经使用 Tauri、Python、SQLite 等技术，请调整为纯 Web 架构。

如果尚未完成第一阶段，则直接按新架构开发。

保留已经完成且可复用的 React、TypeScript、CSS 和算法代码。

完成后必须启动 Vite 开发服务器，实际打开网页验证。

最终要求：

用户能够通过浏览器打开 ARTKNIT STUDIO，上传图片，看到工作台界面，并能在本地保存作品。

不要只生成静态页面。
