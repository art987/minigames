## 三、哈希值生成脚本（PowerShell）

```powershell
# 计算单个文件的SHA256哈希值
Get-FileHash -Path "editor-script.js" -Algorithm SHA256

# 批量计算所有源文件哈希值
Get-ChildItem -Path . -Recurse -Include *.js,*.html,*.css | ForEach-Object {
    $hash = Get-FileHash -Path $_.FullName -Algorithm SHA256
    [PSCustomObject]@{
        文件 = $_.Name
        行数 = (Get-Content $_.FullName).Count
        字节数 = $_.Length
        SHA256 = $hash.Hash
    }
} | Format-Table -AutoSize
```
