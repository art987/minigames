## 三、哈希值生成脚本（PowerShell）

将以下脚本保存为 `get-hash.ps1`，在本项目根目录下运行即可生成所有文件的哈希值清单：

```powershell
$files = @(
  'editor-script.js',
  'script.js',
  'cloud-sync.js',
  'frame-categories.js',
  'editor.html',
  'index.html',
  'styles.css',
  'login\index.html'
)
$sha = [System.Security.Cryptography.SHA256]::Create()
$i = 1
foreach($f in $files){
  if(Test-Path $f){
    $bytes  = [System.IO.File]::ReadAllBytes((Resolve-Path $f).Path)
    $hash   = $sha.ComputeHash($bytes)
    $hashStr= [BitConverter]::ToString($hash).Replace('-','').ToLower()
    $lines  = (Get-Content $f | Measure-Object -Line).Lines
    Write-Output ("{0,2}  {1}  {2,6} 行  {3,10} 字节  {4}" -f $i, $f, $lines, $bytes.Length, $hashStr)
    $i++
  }
}
```
